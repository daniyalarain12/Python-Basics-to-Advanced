## 📚 About This Repository

This repository is a complete Python learning resource, organized into chapters that progressively build your skills from the ground up. Whether you're a complete beginner or looking to strengthen your understanding of advanced topics like OOP, decorators, and recursion — this repo has you covered.

---

## 🗂️ Repository Structure

```
Python-Basics-to-Advanced/
│
├── Chapter1/                        # Python Basics (variables, data types, operators)
├── Chapter2/Conditional_Statements/ # If-else, nested conditions, match statements
├── Chapter3-Strings/                # String methods, slicing, formatting
├── Chapter4-Lists-and-Tuples/       # Lists, tuples, list comprehensions
├── Chapter5-Dictionaries/           # Dictionary operations, comprehensions
├── Chapter6-Sets/                   # Set operations, frozen sets
├── Chapter7-Loops/                  # For loops, while loops, loop control
├── Chapter8-Functions/              # Functions, lambda, *args, **kwargs
├── Chapter9-OOP/                    # Classes, objects, inheritance, polymorphism
├── Chapter9-Recursion/              # Recursive functions and problem-solving
├── Chapter10-File-IO/               # Reading & writing files, CSV, JSON
├── Chapter11-Exception-Handling/    # try/except, custom exceptions, finally
├── Chapter12-Modules/               # Built-in & custom modules, packages
├── Chapter13-Decorators/            # Function decorators, class decorators
│
└── Projects/                        # Practical Python projects
```

## 🛠️ Getting Started

### Prerequisites
- Python 3.x installed on your machine
- A code editor (VS Code, PyCharm, etc.)

### Clone the Repository
```bash
git clone https://github.com/daniyalarain12/Python-Basics-to-Advanced.git
cd Python-Basics-to-Advanced
```

### Run Any File
```bash
python Chapter1/filename.py
```
